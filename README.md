# Trekkers Hub 🏔️

## 1. Project Overview

**Trekkers Hub** is a trekking and travel website that showcases popular trekking destinations across Maharashtra, India.

The website helps users explore different trekking packages, learn about the organization, view beautiful trekking photos, and discover new adventure destinations.

It is built using HTML and CSS with a simple, responsive design that works on both desktop and mobile devices.

## 2. Project Objectives

The main objectives of this project are:

- To showcase popular trekking destinations in Maharashtra.
- To display different trekking packages and their prices.
- To provide information about the organization.
- To share trekking experiences through a photo gallery.
- To create a simple and user-friendly website.

## 3. Project Structure

```text
Trekkers Hub/
│
├── index.html       # Home page
├── about.html       # About Us page
├── packages.html    # Trekking packages
├── gallery.html     # Photo gallery
├── style.css        # Website styling
└── README.md        # Project documentation
```

## 4. Website Pages

### Home Page (index.html)
- Introduces the Trekkers Hub website.
- Displays an attractive banner with adventure-themed visuals.
- Highlights popular trekking packages.
- Provides links to explore more packages.

### About Page (about.html)
- Provides information about Trekkers Hub.
- Explains the organization's mission and vision.
- Highlights the trekking experience, safety, and community.

### Packages Page (packages.html)
- Displays available trekking packages.
- Includes trek names, descriptions, and prices.
- Helps visitors explore different trekking options.

### Gallery Page (gallery.html)
- Displays photographs of trekking destinations.
- Showcases scenic mountain views and trekking experiences.
- Uses a grid layout to organize images.

## 5. Technologies Used

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used for styling, layouts, colors, animations, and responsive design.
- **Unsplash:** Used as an external source for trekking and nature images.

## 6. Key Features

- Simple and attractive user interface.
- Responsive design for desktop and mobile devices.
- Easy navigation between different pages.
- Trekking packages with descriptions and prices.
- Photo gallery showcasing beautiful trekking destinations.
- Consistent design across all pages.
- Lightweight website with no backend or database requirements.

## 7. How to Run the Project

You can run this project locally using either of the following methods.

### Method 1: Open Directly

1. Download or clone the project repository.
2. Open the project folder.
3. Double-click on `index.html`.
4. The website will open in your default browser.

### Method 2: Using a Local Server

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python -m http.server 8000
```

4. Open your browser and visit:

```text
http://localhost:8000
```
